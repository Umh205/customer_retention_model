# Project Overview

### The Customer Retention Model is a predictive analytics project designed to identify customers at high risk of churn. By pinpointing these customers, businesses can deploy targeted strategies to enhance customer loyalty and improve retention rates. This project not only addresses the critical business challenge of customer churn but also helps optimize resource allocation for retention campaigns.

### Key Features:
- Predictive Analysis: Uses historical customer behavior and transactional data to predict churn likelihood.
- Unsupervised Clustering Comparison: Compares the efficiency and utility of two clustering algorithms:
- K-Means: A centroid-based algorithm, best suited for numeric data.
- K-Prototype: Extends k-means by handling both numeric and categorical data, making it ideal for mixed-type datasets.

### Objectives:
- Identify At-Risk Customers: Segment customers into groups based on churn risk.
- Algorithm Efficiency Comparison: Evaluate the performance, accuracy, and practical implications of k-means and k-prototype clustering for customer retention scenarios.
Insights for Actionable Strategies: Provide actionable insights for retention efforts by understanding the characteristics of high-risk segments.
